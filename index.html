EuroSAT Decision Demo

Browser-based demo of the committed EuroSAT ResNet-18 model with a softmax-confidence abstention layer. Runs entirely offline (model + runtime load from this folder) — no network calls at runtime.

1. ChoosePick an example patch or upload a 64×64 PNG/JPG
2. PredictModel returns top class, confidence & top-3 probabilities

Method
  • Model: ResNet-18 (ImageNet-pretrained), final fc replaced for 10 EuroSAT classes.
  • Weights: exported from eurosat-decision/models/best.pt (sha256 C6C5EED4BE400498D8C43941E1115DA72DCDE94A37D73B358E6182923201716c). Weights are NOT modified.
  • Input size: 64×64 (native EuroSAT patch); no resize to 224.
  • Normalization: ImageNet mean [0.485, 0.456, 0.406] / std [0.229, 0.224, 0.225], applied to RGB pixels in planar NCHW order.
  • Runtime: ONNX via onnxruntime-web (local, no network/CDN).
  • Frozen abstention threshold: 0.50, chosen on validation only — not retuned here.
  • Preprocessing fix: the browser writes each channel to its planar NCHW slice so predictions match PyTorch.
